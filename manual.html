⚾ グラウンドアナウンス 使い方ガイド

少年野球の試合を、プロ野球のような場内アナウンスで盛り上げるための無料ツールです。

もくじ
  1. まず使ってみる（1分）
  2. 試合前日の準備
  3. 試合当日の操作
  4. 声をプロ品質にする（任意・無料）
  5. よくある質問

1. まず使ってみる（1分）

  1. アプリのURLを、パソコンまたはスマホのブラウザで開きます（iPhoneはSafari、Android・パソコンはChrome推奨）
  2. 下の「進行」タブにある「▶ 先攻チームの発表」を押してみてください
  3. チャイムのあと、サンプルチームのスタメン発表が読み上げられれば準備OKです
音が出ないときは、端末の音量と消音モード（iPhoneの横のスイッチ）を確認してください。設定なしで使える「内蔵音声」は端末によって声が変わります。

スマホの場合は、ブラウザのメニューから「ホーム画面に追加」をしておくと、次からアプリのようにワンタップで開けます。

2. 試合前日の準備

選手を登録する

  1. 「チーム」タブを開く
  2. 先攻・後攻それぞれのチーム名と、選手の背番号・名前・守備位置を入力（1〜9行目がスタメン、10行目以降が控え）
  3. 読み方が難しい名前は「よみ」欄にひらがなで入力（読み上げはよみが優先されます）
  4. 「保存」を押す
入力したデータはその端末のそのブラウザに保存されます。試合当日に使う端末で入力してください。

アナウンスの文面を確認する

「設定」タブの「アナウンス文の編集」で、すべての文面を書き換えられます。{選手名} や {打順} の部分には自動で名前や数字が入ります。所属連盟のアナウンスマニュアルがある場合は、その文言に合わせておきましょう。

3. 試合当日の操作

場面操作
試合開始「進行」タブ → 大会名を入力 →「▶ 開始アナウンス」
スタメン発表「進行」タブ →「▶ 先攻チームの発表」「▶ 後攻チームの発表」
打者の紹介「打席」タブ → 攻撃中のチームを選ぶ →「▶ この打者をアナウンス」。再生すると自動で次の打者に進みます
選手交代「交代」タブ → 種類（代打・代走・投手交代・守備交代）と選手を選ぶ →「▶ 交代アナウンス」
試合終了「進行」タブ → 両チームの得点を入力 →「▶ 試合終了アナウンス」
その他整列・ファウルボール注意などの定型文は「進行」タブの下部に。自由な文は「交代」タブの自由入力へ

読み上げを途中で止めたいときは「設定」タブの「■ 停止」を押してください。

スピーカーの用意：スマホやパソコンをBluetoothスピーカーや拡声器につなぐと球場全体に聞こえます。事前に接続テストをしておきましょう。

4. 声をプロ品質にする（任意・無料）

そのままでも使えますが、Googleの音声合成（無料枠：毎月100万文字）を設定すると、プロのナレーターのような自然な声になります。設定は最初の1回だけ、15分ほどです。

  1. Google Cloud にGoogleアカウントでログインし、案内に従って利用登録（本人確認のためクレジットカードの登録が必要ですが、無料枠内なら請求はありません）
  2. Text-to-Speech API のページで「有効にする」を押す
  3. 認証情報ページで「＋認証情報を作成」→「APIキー」→ 表示された AIza… をコピー
  4. （推奨）作ったキーを開き「APIの制限」で Cloud Text-to-Speech API のみに制限して保存
  5. アプリの「設定」タブ → 音声エンジンを「Google Cloud 音声」に変更 → キーを貼り付け → 声は「Chirp 3: HD」グループ（Leda・Koreなどお好みで）→「テスト再生」
APIキーは自分専用です。あなたのGoogleアカウントに紐づくため、他の人に教えたりSNSに書いたりしないでください。チームの別の担当者が使う場合は、その人が自分のキーを作ります（無料枠は1人ずつ付きます）。

5. よくある質問

Q. 料金はかかりますか？

アプリ自体は無料です。内蔵音声も無料。Google Cloud音声も月100万文字（打者アナウンス約4万回分）まで無料で、通常の利用で超えることはまずありません。

Q. 電波のない球場でも使えますか？

内蔵音声なら使えます（設定タブでいつでも切り替え可能）。Google Cloud音声はネット接続が必要です。

Q. 名前の読み方が違います

「チーム」タブのその選手の「よみ」欄にひらがなで正しい読みを入れて保存してください。

Q. 入力したデータが消えました

データは端末のブラウザごとに保存されます。別の端末・別のブラウザ・プライベートモードでは引き継がれません。いつも同じ端末の同じブラウザで開いてください。

Q. 音が出ません

端末の音量・消音モードを確認 → 「設定」タブの「テスト再生」で確認 → それでも出なければページを再読み込みしてください。

Q. 文面を元に戻したい

「設定」タブの「初期の文面に戻す」、選手データは「チーム」タブの「サンプルに戻す」で戻せます。

このツールは有志によって作られた無料ツールです。アナウンス文面はお使いの連盟の規定に合わせて調整してください。
