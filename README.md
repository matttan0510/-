# グラウンドアナウンス ⚾

少年野球の試合を、プロ野球のような場内アナウンスで盛り上げるためのウェブアプリです。
スマートフォンやタブレットのブラウザで開き、スピーカーにつなげばそのまま使えます。

## 特長

- **サーバー不要・無料** — ブラウザ内蔵の音声合成（Web Speech API）で日本語を読み上げます。インストール不要で、`index.html` を開くだけで動きます。
- **試合の流れに沿った画面構成**
  - **進行**: 試合開始・スターティングメンバー発表・試合終了・その他の定型アナウンス
  - **打席**: 打順リストから現在の打者をワンタップでアナウンス（自動で次の打者へ）
  - **交代**: 代打・代走・投手交代・守備交代のアナウンスを自動生成、自由入力も可能
  - **チーム**: 両チームの選手名簿（背番号・名前・よみ・守備位置）を登録
  - **設定**: 声の種類・速さ・高さ、アナウンス前のチャイム、文面の編集
- **文面はすべて編集可能** — 所属連盟のアナウンスマニュアル（ボーイズリーグ等）の正式な文言に合わせて、`{選手名}` などの差し込みタグを使って自由に書き換えられます。
- **よみがな対応** — 子どもの名前は読み方が難しいことが多いので、「よみ」欄にひらがなを入れると読み上げに使われます。
- **データは端末に保存** — 選手名簿や文面は localStorage に保存され、次回も残ります（サーバーには送信されません）。

## 使い方

1. `index.html` をブラウザで開く（GitHub Pages 等で公開すると URL でアクセスできます）
2. 「チーム」タブで両チームの選手を登録して保存
3. 「設定」タブで声・速さを調整し、テスト再生で確認
4. 試合中は「進行」「打席」「交代」タブの ▶ ボタンを押すだけ

推奨ブラウザ: iPhone / iPad は Safari、Android / PC は Chrome。

## GitHub Pages での公開

リポジトリの Settings → Pages → Branch でこのブランチ（またはマージ後の main）を選ぶと、
`https://<ユーザー名>.github.io/<リポジトリ名>/` で誰でもアクセスできるようになります。

## 音声品質を上げたい場合

ブラウザ内蔵音声で十分実用になりますが、より自然な声にしたい場合はクラウドの音声合成 API に差し替えられます。

| サービス | 特徴 |
|---|---|
| VOICEVOX | 無料・日本語特化。ローカルまたはサーバーで動かして音声ファイルを生成 |
| Google Cloud Text-to-Speech | 高品質な日本語 WaveNet 音声。従量課金（無料枠あり） |
| Amazon Polly / Azure Speech | 同上。読みの制御（SSML）が細かくできる |
| ElevenLabs | 最も自然だが有料。声のクローンも可能 |

いずれも API キーが必要になるため、導入する場合は小さなサーバー（または事前生成した音声ファイル）を挟む構成がおすすめです。

## 注意

- 初期データはサンプルの架空チーム・選手名です。実際の利用時は「チーム」タブで書き換えてください。
- アナウンス文面の初期値は一般的なアマチュア野球の慣例に基づくものです。所属連盟の公式マニュアルがある場合は「設定」タブの文面編集で正式な文言に合わせてください。
